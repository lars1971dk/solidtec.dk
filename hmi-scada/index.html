Bedre overblik for operatører og teknikere

Et godt HMI skal gøre anlæggets tilstand tydelig og hjælpe operatøren med at handle sikkert og hurtigt. SOLIDTEC udvikler og videreudvikler brugerflader og SCADA-løsninger til industriel produktion.

Vi arbejder med struktur, alarmer, procesvisning og samspil mellem PLC og brugerflade. Eksisterende funktioner og produktionskrav afdækkes, før vi foreslår ændringer.

Vi kan hjælpe med at beskrive, hvilke informationer der bør vises, og hvordan løsningen kan testes inden idriftsættelse.

Hvad kan vi hjælpe med?

  • HMI-design og operatørbilleder
  • SCADA og produktionsdata
  • Alarmer og hændelseshistorik
  • Integration mellem PLC og operatørsystem
